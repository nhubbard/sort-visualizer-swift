Index Sort solo se aplica a una permutación de n enteros consecutivos, cada uno presente una sola vez. Si el mínimo es m, el destino exacto de un valor v es el índice v − m. El algoritmo recorre el arreglo y, en cada posición, intercambia el valor actual con el contenido de su destino hasta que esa posición contiene el valor correcto. No necesita comparar parejas para descubrir el orden. La condición de enteros consecutivos y únicos es indispensable; sin ella, la fórmula podría producir destinos repetidos o inexistentes.
