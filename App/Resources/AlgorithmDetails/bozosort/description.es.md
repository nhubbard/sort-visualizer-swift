Bozosort repite intercambios aleatorios de dos posiciones hasta que el arreglo queda ordenado. Después de cada intercambio comprueba todo el arreglo. Se parece a Bogosort, pero cambia solo dos elementos por intento en lugar de generar una permutación completa. Las posiciones se escogen independientemente, por lo que un intento puede elegir dos veces la misma posición o deshacer un avance anterior. Termina con probabilidad uno si sigue intentándolo, pero no ofrece un límite determinista útil para el tiempo de ejecución.
