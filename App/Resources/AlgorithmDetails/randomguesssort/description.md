Random Guess Sort enumerates candidate arrangements of *indices* rather than values. It starts with an array of *n* zero indices and advances it as a base-*n* counter, with the first output position changing fastest. Each counter state chooses one original input index for each output position. Guesses may repeat indices, so they need not be permutations.

At each state, the algorithm checks whether the referenced values are non-decreasing. When two values are equal, their original indices must also be increasing. The first guess that passes is copied back into the array. Enumerating guesses makes the procedure finite and reproducible for small supported inputs; it can still take up to *n*ⁿ candidates.
