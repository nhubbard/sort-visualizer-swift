Random Guess Sort genera secuencias candidatas de índices de entrada mediante un contador en base n. Cada estado propone un índice de origen para cada posición de salida; algunos estados repiten índices y no forman permutaciones. Comprueba si los valores señalados están en orden no descendente y usa los índices originales para resolver empates. Cuando encuentra una asignación válida la copia al arreglo. La enumeración es finita para una entrada pequeña, pero el número de estados crece como nⁿ.
