Synchronous Sqrt Sort is a stable [merge sort](https://en.wikipedia.org/wiki/Merge_sort) that processes every run of a given length before doubling the run length. It uses a temporary prefix whose length is proportional to the square root of the input length. The remaining values are built into sorted runs through forward merges that move into the vacated prefix space.

After the first block-sized runs are built, the algorithm merges from the end of the array. It orders whole blocks by their first values and stores tags identifying the original half of each block. A backward merge uses those tags to decide which stream supplies an equal value. The saved prefix is merged into the front at the end. The block arrangement uses O(√n) auxiliary space and has O(n log n) worst-case time.

A simpler stable variant follows the same synchronized run-doubling schedule with a bounded-buffer merge. Each pass merges all adjacent runs of one length. A merge that fits in the square-root-sized buffer is copied directly; a larger merge is partitioned and rotated before the smaller regions are merged recursively. This variant uses a different merge mechanism from the tagged-block version.
