KotaSort is a stable in-place block-merge sorting algorithm. It gathers distinct values from the input to form an internal movement buffer and a set of block tags. The algorithm builds sorted runs, alternates the direction of later merge passes, and uses the tags to select and restore blocks while moving the buffer through the array. After merging, it sorts and reinserts the displaced values.

When the input has too few distinct values for the internal buffers, this variant uses stable in-place merging. The block-merge path is designed for O(n log n) time with O(1) auxiliary space. The low-distinctness fallback can take O(n²) time. This fallback avoids moving blocks without enough distinct tags to identify their original order.
