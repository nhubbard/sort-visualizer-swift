Tim Sort is a stable, adaptive [merge sort](https://en.wikipedia.org/wiki/Merge_sort) devised by Tim Peters. It scans for naturally ordered runs, reverses strictly descending runs, and extends short runs with binary insertion sort. Strict descent matters for stability: reversing a run that contains equal elements could change their original order.

The algorithm holds pending runs on a stack. It merges adjacent runs when their lengths violate balance rules, then merges the remaining runs at the end. In the full algorithm, a merge copies the shorter run into temporary storage and can switch from element-by-element comparisons to exponential searches called galloping when one run wins repeatedly. This gives O(n) time on already ordered input and O(n log n) time in the worst case, with O(n) auxiliary space. This variant retains run detection, minimum-run extension, and the balanced stack, but its stable merges omit galloping.
