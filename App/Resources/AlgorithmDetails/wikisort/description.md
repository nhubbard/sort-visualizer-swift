WikiSort is a stable, in-place block-merge sorting algorithm. It divides the input into nearly equal short runs, sorts them, and repeatedly merges adjacent runs. At larger merge levels, it pulls distinct values from the input to form internal buffers. One buffer tags blocks from the left run, while another helps merge blocks as they are placed. The values taken for the buffers are redistributed into sorted order after each level.

When a run has too few distinct values to form the internal buffers, WikiSort merges by binary searches and rotations. Its zero-cache variant uses O(1) auxiliary space and has O(n log n) worst-case time. The internal-buffer and tagged-block phases reduce the number of rotations when enough distinct values are available.
