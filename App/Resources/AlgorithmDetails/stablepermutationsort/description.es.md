Stable Permutation Sort explora permutaciones hasta encontrar una que esté ordenada y mantenga el orden original de los elementos iguales. Usa una recursión relacionada con el algoritmo de Heap, pero avanza mediante rotaciones de cadenas de posiciones en vez de simples intercambios. Un arreglo de índices recuerda el origen de cada elemento durante los cambios y el retroceso. La búsqueda exhaustiva es muy costosa; la estabilidad procede de restringir qué disposición ordenada se acepta.
