Fun Sort repite búsquedas binarias sobre un arreglo que aún no está completamente ordenado. Cada búsqueda propone una posición y el algoritmo intercambia allí el elemento antes de volver a buscar. Para evitar ambigüedades con duplicados, compara una clave compuesta por el valor y su posición original. Esta segunda parte distingue elementos iguales y permite reconocer la convergencia a una permutación definida. El método es una exploración de cómo una búsqueda usada fuera de su condición habitual puede acabar produciendo orden mediante repetición.
