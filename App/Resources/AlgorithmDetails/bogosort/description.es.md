Bogosort genera permutaciones del arreglo hasta encontrar una que esté ordenada. En la variante aleatoria mezcla todos los elementos después de cada comprobación fallida; otra variante puede enumerar las permutaciones de forma determinista. Si la mezcla es uniforme, la probabilidad de acertar en un intento es pequeña y el tiempo esperado crece de manera factorial con el tamaño. No aprovecha comparaciones anteriores para acercarse al resultado. Es un ejemplo del método de generar y comprobar, no un procedimiento práctico para arreglos grandes.
