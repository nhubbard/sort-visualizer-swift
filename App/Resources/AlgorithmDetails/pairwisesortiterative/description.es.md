La ordenación por pares iterativa ejecuta una red de comparadores de Ian Parberry. Recorre etapas con saltos y parejas de posiciones fijados de antemano para cada tamaño del arreglo. Los comparadores intercambian valores invertidos, pero el calendario completo de comparaciones permanece idéntico para todas las entradas de igual longitud. Esta regularidad permite agrupar comparaciones independientes para hardware o ejecución paralela. La implementación usa bucles en lugar de expresar las etapas mediante recursión.
