Block Insertion Sort aprovecha las secuencias que ya aparecen ordenadas en la entrada. Desde la posición actual detecta una secuencia ascendente o una estrictamente descendente; esta última se invierte para dejarla ascendente. Luego incorpora la secuencia al prefijo ya ordenado. Un bloque de un elemento se inserta con desplazamientos normales; para bloques mayores busca límites y mueve grupos de valores. Al trabajar con bloques ordenados puede reducir los movimientos cuando la entrada contiene tramos naturales extensos.
