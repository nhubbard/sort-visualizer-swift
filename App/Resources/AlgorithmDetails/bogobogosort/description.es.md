Bogo Bogo Sort aplica el método de generar y comprobar también a la propia comprobación del orden. Para decidir si un intervalo está ordenado, crea una copia, ordena recursivamente sus primeros n − 1 elementos y mezcla la copia hasta que su parte final cumple la condición requerida. Después compara la copia con el intervalo original. Si no coincide, vuelve a mezclar el original y repite todo el proceso. Esta recursión anidada lo hace mucho más lento que Bogosort; sirve para estudiar una construcción deliberadamente ineficiente.
