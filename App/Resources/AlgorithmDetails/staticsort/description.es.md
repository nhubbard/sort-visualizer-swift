Static Sort distribuye n elementos en exactamente n cubetas, independientemente de la amplitud del intervalo de valores. Una fórmula lineal basada en el mínimo y el máximo asigna a cada elemento una cubeta. Reúne después las cubetas por orden y corrige el orden dentro de las que contienen varios elementos. La disposición es «estática» porque el número de cubetas se decide a partir de n antes de observar cómo se reparten los valores. La eficacia depende de la distribución y de las colisiones dentro de las cubetas.
