Ecta Sort is a stable [merge sort](https://en.wikipedia.org/wiki/Merge_sort) that begins with short insertion-sorted runs and uses part of the array as workspace while merging them. The run length is chosen by repeatedly halving the input length until it falls below 32. Binary insertion places each new element after existing equals, preserving their original order.

For inputs shorter than 256 elements, Ecta Sort saves one half in a temporary buffer, sorts the other half using the vacated space, then exchanges their roles and merges the saved half with the sorted remainder. The merge moves from the end of each pair of runs toward the front. On a tie, it takes the right value first while writing backward, leaving the left value earlier in the final order. The same half-buffer method can sort larger arrays, although its storage then grows linearly.

For larger inputs, it reserves a smaller prefix buffer and divides the remaining data into blocks. Forward and backward merge passes use vacant blocks as workspace. A separate sequence of tags records where each completed block belongs; cycle moves then restore the blocks to merge order. The saved prefix is merged back at the end. This block arrangement reduces auxiliary storage to O(√n), while the repeated merge passes take O(n log n) time in the best, average, and worst cases.
