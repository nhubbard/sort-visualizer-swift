Adaptive Grail Sort is a stable, in-place variant of [Grail Sort](https://en.wikipedia.org/wiki/Block_sort) that adapts its merge strategy to existing order and the number of distinct values in the input. It detects ascending and descending runs, extending short runs with insertion sort. A strictly descending run can be reversed without changing the order of equal values.

The algorithm draws distinct keys from one end of the array to label blocks and reserve a buffer within the input. It selects the end with the more useful run, merges blocks using that internal buffer, and restores the keys afterward. When too few distinct keys are available, it uses smaller buffers or stable in-place merges. These choices retain O(n log n) worst-case time and O(1) extra space. Whole-array run detection allows an already ordered input to finish in O(n) time before block merging begins.
