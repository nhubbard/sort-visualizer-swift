Gravity Sort, also known as Bead Sort, is a natural sorting algorithm that models each value in the input as a row of beads hanging on a rack of vertical rods, one rod per position in the array. If a value is `v`, then `v` beads are threaded onto that row's rods, starting from the first rod. When the whole rack of beads is released and allowed to fall under gravity, each bead drops until it lands on top of another bead or the ground below its rod. Reading the number of beads resting on each rod from left to right, after everything has settled, yields the input values in ascending order — the physical act of falling has performed the sort.

Bead Sort is only well-defined for non-negative integers, since a "row of beads" cannot represent a fractional or negative count. It is also considerably more of a thought experiment than a general-purpose algorithm: mechanical or optical hardware implementations that let beads fall in parallel can sort in roughly linear time, but any conventional sequential simulation of the same falling process tends to cost time proportional to the number of positions multiplied by the range of values involved, since every rod's bead count needs to be reconciled against every other rod's as the columns settle.

This implementation reaches the same sorted result without simulating any literal falling beads. It first shifts every value down by the array's minimum, then tallies how many elements share each shifted value. A backward running sum turns that per-value tally into a "how many beads are resting at or above this height" count for every possible height — precisely the information gravity would have produced column by column, computed instead as a single pass over the tally. A final reconstruction pass then walks every height from tallest to shortest and, for every array position, adds back exactly the bead it should have gained at that height while subtracting out the bead it already started with, arriving at the same settled heights a physical bead rack would have produced.
