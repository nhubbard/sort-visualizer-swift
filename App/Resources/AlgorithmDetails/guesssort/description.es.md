Guess Sort enumera candidatos formados por índices de la entrada. Trata cada posición de salida como un dígito en base n y avanza ese contador para generar nuevas asignaciones. Para cada candidato comprueba todas las parejas de posiciones: rechaza índices de origen repetidos y valores que no respeten el orden. Solo acepta una asignación que use cada elemento una vez y produzca una secuencia ordenada. La enumeración crece extremadamente deprisa y la comprobación por parejas añade trabajo; esta variante muestra un enfoque exhaustivo de generación y prueba.
